# MetricTrace — Metric Definition Reviewer

Install `metrictrace-lite` on Windows Python 3.11, copy this folder into an
agent host that supports `SKILL.md`, and supply authorized metric SQL plus
CSV/Parquet evidence. No API key is required.

Run `python -m pytest app/tests/test_regression.py -q` from the backend source
tree to validate the shared execution engine.
