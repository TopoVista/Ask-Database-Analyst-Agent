# MetricTrace Lite 0.2.0rc2 candidate

This local candidate adds static SQL lineage inspection across the SDK, CLI,
MCP, and authenticated Platform API client paths. It also adds deterministic
decision-report reproduction and retention-bounded snapshot-attempt cleanup
primitives. It does not publish, submit, or claim marketplace approval.

Validated environment: Windows with Python 3.11. Linux and macOS have not
been validated for this candidate.

Artifacts and their SHA-256 values are recorded in
`release/SHA256SUMS-0.2.0rc2.txt`. Earlier 0.1.0 and 0.2.0rc1 artifacts are
preserved unchanged.
